# ObjPad

* Автор: Christopher Duffley <nvda@chrisduffley.com>, первоначально Joseph Lee, Cleverson Uliana и другие

Выполняет различные команды для работы с объектами NVDA одним нажатием клавиши, включая навигацию и многое другое.

## Команды

* Control+NVDA+TAB: переключение между режимами управления стрелками (см. ниже).

## Режимы управления стрелками

Дополнение предоставляет четыре способа использования клавиш со стрелками:

* Классический (или нормальный режим): клавиши стрелок взаимодействуют с системным курсором.
* Объектная навигатция: клавиши стрелок позволяют перемещаться по следующему, предыдущему, родительскому и первому дочернему элементам.
* Режим обзора: используются клавиши со стрелками для переключения между элементами режима обзора (включая веб-страницы) и перемещения между ними.
* Режим сканирования: используются клавиши со стрелками для перемещения по объектам на экране независимо от их иерархии.

В режиме объектной навигации, клавиши со стрелками выполняют следующие команды:

* Стрелка вправо: следующий объект.
* Стрелка влево: предыдущий объект.
* Стрелка вверх: родительский объект.
* Стрелка вниз: первый дочерний объект.
* Пробел или ENTER: активировать объект.

В режиме обзора (элементы отображаются по умолчанию (перемещение по объекту/всем элементам): заголовок, таблица, ссылка, поле формы, список; дополнительные элементы режима обзора можно добавить через настройки режима обзора NVDA или через специальный интерфейс настроек ObjPad (см. ниже)):

* Стрелка вправо: следующий элемент.
* Стрелка влево: предыдущий элемент.
* Стрелка вверх: предыдущий тип элемента.
* Стрелка вниз: следующий тип элемента.
* Пробел или ENTER: активировать объект.

В режиме сканирования:

* Стрелка вниз: следующий объект или следующая строка.
* Стрелка вверх: предыдущий объект или предыдущая строка.
* Стрелка вправо: просмотр следующего символа.
* Стрелка влево: предыдущий символ.
* Control+стрелка вправо: следующее слово.
* Control+стрелка влево: предыдущее слово.
* Пробел или ENTER: активировать объект.

## Настройки ObjPad

В NVDA 2026.2 добавлена специальная настройка для конфигурации доступных элементов навигации в режиме обзора, предназначенных для использования в сенсорном режиме. При установке NVDA на компьютер с сенсорным экраном эту настройку можно найти в параметрах режима обзора. На устройствах без сенсорного экрана или в переносных версиях NVDA ObjPad предлагает ту же настройку через интерфейс настроек ObjPad (часть экрана настроек NVDA).

Список изменений, вносимых между каждыми выпусками дополнения, смотрите в документе [список изменений для выпусков дополнения][1].
